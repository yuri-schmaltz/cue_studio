Como executar

1. Validar tudo (sem tocar código)

bash _reversa_forward/plano-2026-10-04/scripts/run_all_prototypes.sh

2. Liberar a política

Edite .reversa/reversa-config.json e troque allowLegacyEdits para true (com ou sem allowedPaths).

3. Aplicar patches do ciclo 0

git checkout -b feature/ciclo-0
git apply _reversa_forward/plano-2026-10-04/patches/*.patch

4. Verificar com os testes prontos

python3 -m pytest _reversa_forward/plano-2026-10-04/tests/
cd ui && npx playwright test _reversa_forward/plano-2026-10-04/e2e/
