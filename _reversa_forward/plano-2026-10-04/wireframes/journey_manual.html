Jornada: Geração manual (Studio)

Criador que ignora o Director e gera uma peça única no Studio (A13).

Passos

1. Abrir Studio Origem: Sidebar → Studio (sem projeto obrigatório). Layout: Controles / Resultados.
2. Definir parâmetros Prompt, modelo, duração, seed, referências. Próxima ação: “Gerar”.
3. Acompanhar Resultado aparece em ≤ 1 toque do mobile (A13). Status: queued / preparing / running / done / failed.
4. Salvar Origem: botão “Salvar no projeto” — abre diálogo para escolher destino (projeto existente ou criar).

Pontos de erro

Sem projeto aberto Ação: “Criar projeto agora” (deep-link via A09).
